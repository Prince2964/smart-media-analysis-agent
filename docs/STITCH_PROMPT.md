# Stitch generation brief

Create a complete responsive web application design named SMART MEDIA ANALYSIS AGENT for a university AI-103 demonstration. Apply the attached DESIGN.md as the visual source of truth. This is a media analysis product, not an analytics dashboard. Design all 14 states listed in DESIGN.md and one mobile composition with consistent reusable components.

The main task is: choose Upload Video, Upload Image, or Paste Link; submit media; see processing stages; read a Media Intelligence Report; ask grounded questions with citations. Report sections must be Summary, Main Topics, Transcript / Extracted Content, Important Moments, Key Information. Questions area must read Ask About Your Media and include Ask a question about this media... and an Ask button.

Use a neutral zinc canvas, one deep teal accent #24766D, Geist / Geist Mono, clean spacing, thin dividers, restrained corners and asymmetry. Desktop report plus a narrower chat panel; single-column mobile. No decorative animation or generic KPI tiles. Make the three input modes unmistakable.

Use clearly labeled sample content for a fictional product briefing. Example question: When did they discuss pricing? Example answer: The pricing discussion starts at approximately 01:32. Show a source citation and prominent timestamp. Another answer must demonstrate: I can't determine that from the provided media. Distinguish directly extracted content, retrieved context, and generated explanation. Show mock mode honestly; Azure is not connected. Do not fabricate credentials or configuration.

Include selected-file, validation, unsupported-link, processing failure, retry, no-results, empty, and completion variants. Link processing supports only registered adapters and does not imply universal downloading or mandatory YouTube support. Label all fields, preserve visible keyboard focus, use 44px touch targets and high-contrast text. Keep report and chat usable on mobile without horizontal scrolling.

Deliver the screens for review and export their screenshots and HTML/assets so the local React implementation can closely match the approved Stitch output.
